# BurnoutLab

BurnoutLab is a retired resume-scoring utility.

The public site is closed and must not collect or transmit resume data. The repository now contains only a local, non-networked demonstration of how report rendering could work.

## Security notes

- There are no API keys, credentials, or third-party service calls in this demo.
- The former API request has been removed.
- Demo output is rendered with `textContent`, not `innerHTML`.
- Do not add real resume processing, secrets, or external API calls to this static demo.

The previously deployed site and API should be disabled separately in their hosting/provider dashboards.
